Separate scripts vs one script with steps for impute tools:

Keep them separate (impute5.sh, minimac.sh, beagle.sh, run_grits.sh). They have completely different binaries, flags, and I/O formats — cramming them into one step-based script would make each section awkward and the --help confusing. The unified interface already exists downstream in run_accuracy.sh. What each script should gain is a --species maize|cassava flag and a --map-dir flag so the 4 settings (maize/cassava × map/nomap) are handled inside each script without needing separate copies.
