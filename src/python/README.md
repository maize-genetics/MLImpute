# Directory Descriptions

### bed_io
- scripts to create bed files

### cross
- seq_sim python scripts

### ps4g_io
- scripts to load ps4g files

### supervised
- model architecture
- training scripts
- inference scripts

### vcf_eval
- SNP accuracy script

### visualization
- scripts to visualize heatmaps and predictions
